# 🚀 Amugona_Solver

> **"결정 장애는 이제 그만! 우리들만의 유쾌한 복불복 해결사"**

---

## 📌 1. 프로젝트 개요
* **과목명:** 컴퓨팅사고와 SW코딩 [cite: 4]
* **프로젝트 이름:** 오늘 뭐 먹지? GUI 복불복 사다리 (WhatToEat Today - GUI Edition)
* **결과물 형태:** 데스크톱 GUI 애플리케이션 (Python `tkinter` 활용) [cite: 69, 175]
* **예상 사용자:** 학식 메뉴를 고를 때마다 선택 장애가 오는 **나 자신**과 조별과제 모임에서 커피 내기를 즐기는 **대학생 친구들** [cite: 68]

---

## 💡 2. 한 문장 설명
본 프로그램은 점심 메뉴 선택이나 비용 지불자 선정 등 일상의 사소한 결정 장애 상황을 친구들과 함께 유쾌하게 해결할 수 있도록 돕는 그래픽(GUI) 기반 복불복 셔플 프로그램입니다.

---

## 🔍 3. 풀려는 문제 및 동기
* **일상의 불편함:** 매번 점심시간마다 "아무거나"를 외치며 메뉴 선택을 미루거나, 조별과제 후 간식비 내기를 할 때 불필요한 눈치싸움과 시간 낭비가 발생하는 불편함이 있었습니다.
* **개발 필요성:** 단순한 텍스트 입력 창(CLI)을 넘어, 시각적인 버튼과 명확한 윈도우 창을 통해 누구나 직관적으로 조작하고 결과를 함께 즐길 수 있는 깔끔한 데스크톱 앱이 필요하다고 느꼈습니다.
* **학습 목적:** 비전공자 수준에서 다룰 수 있는 리스트와 난수 제어 문법을 극대화하여, 직접 화면을 클릭하며 긴장감 넘치게 결과를 확인할 수 있는 '만들 때도 재미있고 사용할 때도 유쾌한' 프로그램을 만들고자 합니다.

## 🛠️ 4. 핵심 기능 목록 (우선순위)

| 우선순위 | 기능 이름 | 상세 내용 |
| :--- | :--- | :--- |
| **MUST** | **입력 폼 및 명단 관리** | 프로그램 창에서 참가자 이름과 메뉴 후보(또는 벌칙)를 각각 입력받아 화면 내 리스트 박스에 실시간으로 시각화 |
| **MUST** | **복불복 매칭 및 팝업** | '결과 보기' 버튼을 누르면 무작위 매칭 로직을 통해 데이터를 매칭하고, 최종 결과를 새로운 메시지 창(팝업)으로 출력  |
| **NICE** | **결과 기록 저장 및 뷰어** | 내기 결과가 조작되지 않았음을 증명하기 위해, 역대 당첨자 기록을 텍스트 파일(.txt)에 자동으로 누적 저장하고 화면에 출력  |

## 💻 5. 사용할 Python 개념 및 기술 스택
* **`tkinter` 라이브러리:** 윈도우 창 생성, 버튼(`Button`), 입력창(`Entry`), 라벨(`Label`) 등 기본 위젯을 배치하고 그래픽 화면을 구성합니다.
* **사용자 정의 함수 (`def`):** 버튼을 클릭했을 때 실행될 이벤트 함수(예: 명단 추가 함수, random 매칭 함수)를 구조화하여 설계합니다.
* **자료구조 (리스트):** 사용자가 화면에 입력한 참가자 명단과 메뉴 목록을 파이썬 리스트에 순서대로 담아 관리합니다.
* **`random` 모듈:** `random.shuffle()` 등을 활용하여 버튼을 클릭하는 순간 리스트 내부 데이터를 공정하게 무작위로 뒤섞습니다.
* **파일 입출력 (`open()`):** 복불복 매칭의 히스토리를 보존하기 위해 외부 텍스트 파일을 생성하고 데이터를 쓰고 읽는 백엔드 로직을 활용합니다.
