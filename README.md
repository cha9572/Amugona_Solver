# 🚀 Amugona_Solver

> **"결정 장애는 이제 그만! 우리들만의 유쾌한 복불복 해결사"**

---

## 📌 1. 프로젝트 개요
* **과목명:** 컴퓨팅사고와 SW코딩
* **프로젝트 이름:** 오늘 뭐 먹지? GUI 복불복 사다리 (WhatToEat Today - GUI Edition)
* **결과물 형태:** 데스크톱 GUI 애플리케이션 (Python `customtkinter`, `tkinter` 활용)
* **예상 사용자:** 학식 메뉴를 고를 때마다 선택 장애가 오는 **나 자신**과 조별과제 모임에서 밥값을 내거나 메뉴를 고르는 **대학생 친구들**

---

## 💡 2. 한 문장 설명
본 프로그램은 점심 메뉴 선택 등 일상의 사소한 결정 장애 상황을 친구들과 함께 유쾌하게 해결할 수 있도록 돕는 그래픽(GUI) 기반 복불복 슬롯머신 및 맛집 추천 프로그램입니다.

---

## 🔍 3. 풀려는 문제 및 동기
* **일상의 불편함:** 매번 점심시간마다 "아무거나"를 외치며 메뉴 선택을 미루거나, 근처에 어떤 식당이 있는지 몰라 검색에 시간을 낭비하는 불편함이 있었습니다.
* **개발 필요성:** 단순한 텍스트 입력 창(CLI)을 넘어, 시각적인 버튼과 명확한 윈도우 창을 통해 누구나 직관적으로 조작하고 결과를 함께 즐길 수 있는 깔끔한 앱이 필요했습니다. 특히 내 주변 맛집을 자동으로 불러오는 기능이 있다면 결정이 훨씬 쉬워질 것이라 판단했습니다.
* **학습 목적:** 파이썬의 외부 라이브러리 연동(`requests`, `customtkinter`) 및 API 활용 능력을 기르고, 캔버스(`Canvas`)를 이용한 동적 애니메이션을 구현하여 '만들 때도 재미있고 사용할 때도 유쾌한' 프로그램을 만들고자 합니다.

## 🛠️ 4. 핵심 기능 목록

| 우선순위 | 기능 이름 | 상세 내용 |
| :--- | :--- | :--- |
| **MUST** | **카카오 API 기반 주변 맛집 탐색** | 사용자의 위치(IP 또는 직접 입력한 주소)를 기반으로 카카오 로컬 API를 호출하여 한식/중식 등 카테고리별 주변 맛집을 메뉴 후보에 자동으로 추가 |
| **MUST** | **슬롯머신 룰렛 애니메이션** | '결과 보기' 버튼을 누르면 캔버스(Canvas)를 통해 글자들이 가로로 빠르게 스크롤되다가 서서히 멈추는 역동적인 슬롯머신 애니메이션 제공 |
| **MUST** | **직관적인 메뉴 관리 폼** | 모던한 UI(CustomTkinter)에서 사용자가 직접 메뉴를 추가/삭제하고, 전체 초기화를 할 수 있는 리스트 관리 기능 |
| **NICE** | **결과 기록 자동 저장 및 뷰어** | 내기 결과가 조작되지 않았음을 증명하기 위해, 역대 당첨 기록과 시간을 텍스트 파일(.txt)에 누적 저장하고 앱 내 팝업 뷰어로 확인 가능 |

## 💻 5. 사용할 Python 개념 및 기술 스택
* **`customtkinter` & `tkinter`:** 둥근 모서리, 모던한 색상 테마 등 세련된 데스크톱 앱 UI를 구성하고, 캔버스(`Canvas`) 위젯을 통해 슬라이딩 텍스트 애니메이션을 구현합니다.
* **`requests` 모듈 & 카카오 API:** IP 주소 및 카카오 로컬 API 서버와 통신하여 실시간으로 위치 기반 장소 데이터를 JSON 형태로 받아옵니다.
* **`python-dotenv`:** 코드에 API 키를 하드코딩하지 않고 `.env` 파일로 분리하여 보안과 환경 변수를 관리합니다.
* **`random` 모듈:** 불러온 맛집이나 사용자가 추가한 메뉴 리스트를 공정하게 뒤섞고 결과를 무작위로 추출합니다.
* **파일 입출력 (`open()`):** 복불복 히스토리를 영구적으로 보존하기 위해 `.txt` 파일을 생성하고 데이터를 쓰고 읽는 로직을 활용합니다.
